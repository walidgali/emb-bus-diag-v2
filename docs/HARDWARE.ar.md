# دليل العتاد

*English: [HARDWARE.md](HARDWARE.md)*

كل الأمثلة تفترض نظام Linux (Raspberry Pi OS أو Ubuntu أو Debian). نفّذ `./emb-bus-diag-v2 --help` لعرض كل الخيارات. جرّب `--bus mock` أولاً للتأكد من سلامة الأداة نفسها.

## I2C (حساس الجهد INA219 وحساس الحرارة TMP102)

1. فعّل الناقل: `sudo raspi-config` ثم Interface Options ثم I2C (على Raspberry Pi)، أو حمّل الوحدة `i2c-dev`.
2. وصّل `SDA` و`SCL` و`GND` وجهد 3.3 فولت. لا توصّل أبداً منطق 5 فولت بلوحة Pi.
3. اكتشف الجهاز: `sudo apt install i2c-tools && i2cdetect -y 1`.
4. اقرأه (يجب أن يكون المستخدم في مجموعة `i2c` أو استخدم `sudo`):

```bash
# سجل جهد الناقل في INA219 هو 0x02، والعنوان الافتراضي 0x40
./emb-bus-diag-v2 --bus i2c -b 1 -a 0x40 -r 0x02 --profile ina219 -n 10
# سجل الحرارة في TMP102 هو 0x00، والعنوان الافتراضي 0x48
./emb-bus-diag-v2 --bus i2c -b 1 -a 0x48 -r 0x00 --profile tmp102 -n 10
```

`-b` رقم الناقل (`/dev/i2c-<b>`)، و`-a` العنوان بطول 7 بت (من 0x03 إلى 0x77).

## SPI

عقدة الجهاز هي `/dev/spidev<b>.<a>`: القيمة `-b` رقم الناقل و`-a` خط اختيار الشريحة (CS). النمط 0، 8 بت، سرعة 1 ميغاهرتز. ترسل الأداة بايت السجل ثم تعيد البايتات التي تليه.

```bash
./emb-bus-diag-v2 --bus spi -b 0 -a 0 -r 0x01 --profile raw --metric voltage --scale 0.001
```

## CAN

تقرأ أول إطار بيانات معرّفه يساوي `-a` (وتنتظر حتى ثانية واحدة). اسم الواجهة هو `$EMBDIAG_CAN_IFACE`، وإن لم يوجد فـ `vcan<b>`.

```bash
# واجهة افتراضية للتجربة
sudo modprobe vcan && sudo ip link add dev vcan0 type vcan && sudo ip link set up vcan0
# واجهة حقيقية: sudo ip link set can0 up type can bitrate 500000 ; export EMBDIAG_CAN_IFACE=can0
./emb-bus-diag-v2 --bus can -b 0 -a 0x123 --profile ina219 &
cansend vcan0 123#5DC0          # القيمة 0x5DC0 تعني 12.0 فولت (حزمة can-utils)
```

الخيار `-a` يقبل معرّفات قياسية بطول 11 بت (حتى `0x7FF`) ومعرّفات ممتدة بطول 29 بت (فوق `0x7FF` وحتى `0x1FFFFFFF`). تُتجاوز إطارات الخطأ وRTR وإطارات المعرّفات الأخرى، وتُرفض الإطارات التي فيها بايتات أقل من المطلوب.

## UART

| المتغير | المعنى | الافتراضي |
|---------|--------|-----------|
| `EMBDIAG_UART_DEV` | مسار الجهاز | `/dev/ttyUSB<b>` |
| `EMBDIAG_UART_BAUD` | 9600 أو 19200 أو 38400 أو 57600 أو 115200 | 9600 |
| `EMBDIAG_UART_MODE` | `poll` أو `stream` | `poll` |

الصيغة 8N1 بدون تحكم بالتدفق. للأداة بروتوكولان:

- **poll** (الافتراضي): تفرغ الأداة مدخل المنفذ، ثم ترسل **بايتاً واحداً** (السجل `-r`)، وتنتظر **ردّاً من بايتين** (الأعلى أولاً). يجب أن يرد برنامج الحساس أو المتحكم الدقيق على هذا الطلب.
- **stream**: لا يُرسل شيء؛ تفرغ الأداة المدخل وتأخذ أول بايتين يبثّهما الجهاز. يناسب الأجهزة التي تطبع القيم باستمرار. لا يمكنه إعادة المزامنة إذا ضاع بايت، فيُفضّل `poll` عندما تتحكم بالبرنامج الثابت للجهاز.

غياب الرد خلال ثانية خطأ (رمز الخروج 1).

```bash
export EMBDIAG_UART_DEV=/dev/ttyUSB0 EMBDIAG_UART_BAUD=115200
./emb-bus-diag-v2 --bus uart -r 2 --profile ina219 -n 5
```

أضف مستخدمك إلى مجموعة `dialout` لفتح المنافذ التسلسلية: `sudo usermod -aG dialout $USER` ثم سجّل الدخول من جديد.

## Modbus TCP

معرّف الوحدة هو `-a` وعنوان سجل الاحتفاظ هو `-r`. الخادم: `EMBDIAG_MODBUS_HOST` (الافتراضي `127.0.0.1`) و`EMBDIAG_MODBUS_PORT` (الافتراضي `1502`). يلزم تثبيت `libmodbus-dev` وقت البناء.

```bash
pip install -r requirements-dev.txt
python3 modbus_server.py &                 # السجل 0 = 0x5DC0 أي 12.0 فولت
./emb-bus-diag-v2 --bus modbus -a 1 -r 0 -n 3
```

## قراءة الخرج

```
[3/5] Val=12.0000 V | OK | EMA=12.0000 | Z=0.00 | Trend=0.0000 | Range=0.0000
```

- `Val`: القيمة بعد تطبيق المقياس.
- `OK/WARNING/CRITICAL/ERROR`: حالة القراءة بحسب العتبات.
- `EMA`: القيمة الملساء (معامل 0.2).
- `Z`: درجة Z مقابل العينات السابقة (تحتاج 4 عينات؛ تظهر `OUTLIER` عندما |Z| أكبر من 3).
- `Trend`: ميل خط الاتجاه لكل عينة.
- `Range`: أكبر قيمة ناقص أصغرها.

العتبات مدمجة في الكود (القيمة السليمة داخل النطاق، والخروج منه يرفع الحالة):

| القياس | سليم (OK) | تحذير | حرج | خطأ |
|--------|-----------|-------|-----|-----|
| الجهد (فولت) | من 3.3 إلى 14.2 | أقل من 3.3 أو أكثر من 14.2 | أقل من 3.0 أو أكثر من 14.8 | قيمة سالبة |
| الحرارة (°C) | من 5 إلى 60 | أقل من 5 أو أكثر من 60 | أقل من 0 أو أكثر من 75 | أقل من -40 أو أكثر من 125 |
| الضغط (hPa) | من 950 إلى 1050 | أقل من 950 أو أكثر من 1050 | أقل من 850 أو أكثر من 1080 | أقل من 300 أو أكثر من 1200 |
