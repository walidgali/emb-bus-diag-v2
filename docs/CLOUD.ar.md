# النشر السحابي عبر MQTT

*English: [CLOUD.md](CLOUD.md)*

الخيار `--cloud` ينشر كل قراءة إلى وسيط MQTT. وهو اختياري ويحتاج `libmosquitto` وقت البناء
(`sudo apt install libmosquitto-dev` ثم `make`؛ للإجبار `WITH_MQTT=1` وللتعطيل `WITH_MQTT=0`).
بدونها يطبع `--cloud` رسالة "cloud support is not compiled in" ويخرج برمز 1.

## تجربة محلية

```bash
sudo apt install mosquitto mosquitto-clients
mosquitto -p 1883 -v &                        # الوسيط
mosquitto_sub -t "diag/stats" &               # مستمع
./emb-bus-diag-v2 --bus mock -n 5 --cloud
```

كل سطر يظهر بصيغة `CLOUD: delivered -> {...}` يعني أن الوسيط أكّد استلام تلك الرسالة (QoS 1). شكل الرسالة:

```json
{"device":"emb-bus-diag","ts":1795775413,"raw":3000,"val":12.0000,"unit":"V",
 "status":"OK","ema":11.7000,"z_score":0.00,"samples":2}
```

## الإعداد (متغيرات البيئة)

| المتغير | المعنى | الافتراضي |
|---------|--------|-----------|
| `EMBDIAG_MQTT_HOST` | عنوان الوسيط | `127.0.0.1` |
| `EMBDIAG_MQTT_PORT` | المنفذ | `1883` (و`8883` عند تحديد ملف CA) |
| `EMBDIAG_MQTT_TOPIC` | الموضوع (topic) | `diag/stats` |
| `EMBDIAG_MQTT_USER` / `EMBDIAG_MQTT_PASS` | بيانات الدخول | لا شيء |
| `EMBDIAG_MQTT_CAFILE` | ملف شهادة CA، **ويفعّل TLS** | لا شيء (نص مكشوف) |
| `EMBDIAG_DEVICE_ID` | حقل `device` في الرسالة | `emb-bus-diag` |
| `EMBDIAG_MQTT_ACK_TIMEOUT_MS` | مهلة انتظار تأكيد الوسيط | `3000` |

## السلوك

- اتصال واحد لكل تشغيل، يُفتح قبل أول عينة. إن تعذّر الوصول إلى الوسيط تخرج الأداة برمز 1 دون أخذ أي قياس.
- إن لم تُؤكَّد رسالة، تواصل الأداة أخذ العينات وتكتب التقرير المحلي، وتخرج برمز 1 في النهاية (الرمز 1 يغلب 2).

## الأمان: اقرأ هذا

- **بدون `EMBDIAG_MQTT_CAFILE` تنتقل البيانات وكلمة المرور دون تشفير.** وتطبع الأداة `NOT encrypted` في هذه الحالة. استخدم TLS ووسيطاً يشترط بيانات دخول على أي شبكة لا تتحكم بها كلياً.
- شهادات العميل وتثبيت الشهادة (pinning) غير مدعومة بعد.

## الحدود

- لا إعادة اتصال تلقائية ولا تخزين محلي مؤقت: إن انقطع الوسيط أثناء تشغيل طويل تُعدّ بقية القراءات غير مُسلَّمة ولا تُخزَّن.
- اختُبرت بمكتبة mosquitto وهمية في CI (شكل الرسالة وخيارات TLS وبيانات الدخول والأعطال والمهل)، وعلى وسيط حقيقي في مهمة CI إعلامية. ولم تُستخدم على أجهزة حقيقية أو وسيط إنتاجي.
